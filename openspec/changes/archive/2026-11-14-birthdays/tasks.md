# Tasks

Как работаем:

- **Сначала тест.** Пишем тест, запускаем и видим, что он красный по нужной причине: нет колонки, функции или поля, или результат не тот, а не опечатка в самом тесте. Потом код — тест зелёный. Задача «тесты …» закрыта, когда тесты написаны и красные. Задача «код …» закрыта, когда они зелёные.
- **Каждый сценарий спеки — свой тест.** Где какой — в задачах ниже и в design.md §9.
- **Перед `pnpm test` и `pnpm test:e2e`** запущен `docker compose up -d`. Vitest работает с базой `<имя>_test`, e2e — с `<имя>_e2e_test`; основную локальную базу тесты не трогают.
- **Перед кодом на Next.js** прочитать нужный гайд в `node_modules/next/dist/docs/` (правило `AGENTS.md`). **Перед кодом списка месяцев** — код `Select.Value` в `node_modules/@base-ui/react`: версия закреплена, поведение проверяем по ней.
- **Ручные проверки** — на временной базе: `createdb` рядом с основной в локальном контейнере, запуск из Git Bash с `DATABASE_URL= POSTGRES_DB=<временная>`. Без `DATABASE_URL=` запуск возьмёт основную базу из `.env`. Временную базу потом удалить, основную — нет.
- **`.env` не трогаем:** новых настроек фича не требует.
- **После каждой группы** — `pnpm typecheck`, `pnpm lint`, `pnpm format:check`, `pnpm test`, а с группы 4 и `pnpm test:e2e`. Всё зелёное.
