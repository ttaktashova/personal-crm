# Tasks

Автотестов в проекте нет, а тестовый раннер — новая библиотека (обсуждать с владельцем). Поэтому проверки ниже — `pnpm typecheck`, `pnpm lint`, `pnpm build`, SQL-запросы к локальной базе, разовые проверки через `pnpm tsx -e "…"` и ручные проверки в браузере на `pnpm dev`. - «Коммить и пуш» — по команде владельца: коммит в ветку `keep-in-touch`, push, PR в `main`, ссылка на PR.
- После merge — выкатка через CI; проверить smoke `/health` и главную на проде по design.md (Migration Plan, п. 2); красный smoke — сообщить владельцу, ничего не откатывать.
