# Spec Delta

## ADDED Requirements

### Requirement: «Пора мстить» в выбранной группе
Если на главной выбрана группа, блок «Пора мстить» SHALL показывать только людей из этой группы, с тем же порядком, теми же первыми пятью и строкой «+ещё N людишек», где N считает только эту группу. Если в группе мстить некому, MUST показываться карточка «Пока некому мстить». При «Все» блок показывает всех, как сейчас.

#### Scenario: Только своя группа
- **WHEN** пора мстить Анне из «Теннис» и Борису из «Семья», и владелец выбирает группу «Теннис»
- **THEN** в блоке «Пора мстить» только Анна

#### Scenario: Счёт «+ещё» в группе
- **WHEN** всего пора мстить двенадцати людям, из них восьмерым из группы «Друзья», и владелец выбирает «Друзья»
- **THEN** в блоке пятеро из «Друзья» и строка «+ещё 3 людишки»

#### Scenario: В группе некому мстить
- **WHEN** пора мстить только людям из «Семья», а владелец выбирает «Теннис»
- **THEN** на месте блока карточка «Пока некому мстить» с грустным котиком

#### Scenario: Все
- **WHEN** владелец выбирает «Все»
- **THEN** в блоке «Пора мстить» все, кому пора мстить, как без групп
