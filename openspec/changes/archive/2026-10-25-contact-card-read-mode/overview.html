Карточка для просмотра, правка и добавление в окнах

Карточка перестаёт быть формой: данные показаны текстом, а рядом с именем — карандаш и корзина. Карандаш открывает окно «Редактировать контакт», корзина спрашивает, точно ли удалить. Новый человек добавляется в таком же окне прямо на главной — отдельной страницы больше нет.

1Коротко

  • Карточка контакта открывается в режиме просмотра: только текст, без полей ввода и кнопки «Сохранить».
  • Изменить данные — в окне «Редактировать контакт» по карандашу у имени. Удалить — по корзине у имени, с вопросом «Удалить контакт?».
  • Добавить человека — в окне «Новый чертила» по кнопке «Добавить черта» на главной. Окно такое же, как окно редактирования, только с пустыми полями. Страницы «Новый чертила» больше нет.
  • Даты под именем — без времени и без «г.», по московскому времени. В пустых «Заметках» обоих окон — новая подсказка «Что натворил, что обещал, что припомнить».
  • Это первый шаг перед большой фичей new-features-and-keep-in-touch: история мести, «Как часто припоминать» и «Пора мстить» придут с ней.
  • Статус: спроектирована, код ещё не писали. Отмечено 0 задач из 13. Автотестов (программ, которые сами проходят сценарии) в проекте нет: проверка — сборкой и руками. База данных не меняется, миграций (скриптов, которые меняют устройство базы) нет.

2Что появится на экранах

Наброски, не точные макеты. Имена, даты и тексты — правдоподобные примеры. Точные макеты лежат рядом с фичой — откройте их, чтобы сверить вид:

Карточка · компьютер Карточка · телефон Окно редактирования · компьютер Окно редактирования · телефон

На макетах есть строка «мстили …», поле «Как часто припоминать» и раздел «Последняя месть» — их в этой фиче нет, они придут с большой фичей. На набросках ниже их тоже нет. Отдельного макета окна «Новый чертила» нет: оно повторяет окно редактирования с пустыми полями.

3Как это работает

Карточка — только для чтения

Полей ввода в карточке нет. Изменить что-то можно только через окно «Редактировать контакт».

Даты — без времени и по Москве

Под именем «Добавлен …» и, если карточку меняли позже чем через минуту после создания, «· изменён …». Только число, месяц словом и год.

Контакт добавлен 23 октября в 22:30 по всемирному времени (UTC) — в Москве это уже 24 октября, 01:30 → в карточке «Добавлен 24 октября 2026».
Пустое поле — «не указано»

Касается всех четырёх полей, в том числе «Заметок». Заметки показываются как написаны: с переносами строк и пустыми строками между абзацами.

Окна каждый раз открываются «с чистого листа»

Брошенный ввод не запоминается. «Редактировать контакт» показывает то, что лежит в базе, «Новый чертила» — пустые поля.

Стёрли телефон → «Отмена» → снова «Редактировать» → телефон на месте.
Ввели имя в «Новый чертила» → Esc → снова «Добавить черта» → поля пустые.
Окно закрывается только после ответа сервера

Так работают и «Сохранить» в окне редактирования, и «Добавить черта» в окне добавления.

  • Сохранилось — окно закрывается, страница обновляется без перезагрузки.
  • Ошибка в поле (например, пустое имя) — окно открыто, у поля «Укажите имя», в базе ничего не меняется.
  • Сервер недоступен — окно открыто с введёнными данными и сообщением об ошибке.
  • Контакт успели удалить в другой вкладке, а его правят — сообщение «Этот контакт не найден. Возможно, его удалили.»
Новый человек сразу на виду

После «Добавить черта» поиск на главной сбрасывается, список прокручивается к новому контакту и подсвечивает его. Так было и со страницей — поведение не меняется.

Отдельной страницы добавления больше нет

Добавить человека можно только кнопкой «Добавить черта» на главной. Старый адрес /contacts/new (например, из закладки) показывает «Контакт не найден» с кнопкой «К списку контактов».

Удаление — только после «Удалить» в вопросе

Корзина сама ничего не удаляет: сначала вопрос. «Отмена» оставляет контакт. Удаляется контакт вместе с заметками.

Чего в этой фиче нет

Строки «мстили …», поля «Как часто припоминать», раздела «Последняя месть» и упоминания истории мести в вопросе об удалении. Всё это добавит фича new-features-and-keep-in-touch — её делают после этой.

4Как проверить руками

Подготовка. Запустите приложение локально (pnpm dev, см. README) и откройте главную.

Понадобятся: контакт без почты и без заметок, контакт с заметками из трёх абзацев и отдельный тестовый контакт для удаления — создайте его в окне «Новый чертила» (кнопка «Добавить черта» на главной). Настоящие контакты не удаляйте.

5Что агент решил сам

Продуктовые — стоит просмотреть

Записаны в proposal.md как решения по умолчанию — «их легко поменять».

  • Даты «Добавлен / изменён» — по московскому времени, а не по времени сервера.
  • «· изменён …» — как сейчас: только если меняли позже чем через минуту после создания.
  • Пустые «Заметки» подписаны «не указано», как остальные поля.
  • Телефон и почта — простой текст, а не ссылки для звонка и письма.
  • После сохранения — прежнее сообщение «Изменения сохранены»; окно закрывается только после ответа сервера.
  • Если контакт удалили, пока окно открыто, — сообщение, окно остаётся открытым.
  • Щелчок мимо окна его не закрывает, чтобы не потерять ввод. Касается обоих окон.
  • Окно «Новый чертила» каждый раз открывается пустым: брошенный ввод не запоминается.
  • После добавления — всё как было со страницей: сброс поиска, прокрутка к новому человеку, подсветка, сообщение «Контакт «…» добавлен».
  • Окна «Новый чертила» в макете нет — оно собрано по образцу окна редактирования; название и кнопка «Добавить черта» взяты с прежней страницы.
  • Вопрос об удалении — прежний текст и прежнее сообщение «Контакт «…» удалён».
  • Надпись «Есть несохранённые изменения» убрана: правки в окне видны и так.
  • Из ссылки на макет нельзя понять, какой экран имелся в виду, поэтому рядом с фичой сохранены все её экраны: карточка и окно, компьютер и телефон.

Технические — на экраны не влияют

  • Карточку и главную собирает сервер; в браузере работают только кнопки у имени, кнопка «Добавить черта» и окна.
  • Одна форма и одна оболочка окна на «Новый чертила» и «Редактировать контакт»: поля, подсказки, проверки и поведение не расходятся.
  • После добавления адрес главной обновляется без новой записи в истории браузера: кнопка «Назад» не возвращает к тому же списку.
  • Страница добавления просто удаляется: её старый адрес сам попадает на уже существующую страницу «Контакт не найден», нового кода для этого не нужно.
  • Кнопки у имени нарисованы один раз и только переставляются для телефона — не две копии.
  • Подсказки и окно — готовые компоненты shadcn/ui (библиотеки готовых элементов интерфейса); новых библиотек не добавляется.
  • Часовой пояс — одна настройка в коде; ей же воспользуется большая фича.
  • Серверная часть сохранения и удаления не меняется.
  • Цвета и отступы — только из дизайн-токенов (общих настроек вида) приложения, а не из hex-кодов макета.
  • Копии макетов — как в оригинале, убрана только ссылка на служебный скрипт холста.

Согласовано с вами: что входит в фичу, а что остаётся в большой; «удаление» — это удаление контакта; новая подсказка в «Заметках»; копии макетов как в оригинале; добавление в окне вместо страницы; старый адрес страницы — «не найдено»; требование про ссылку «Весь список» переехало в спеку карточки.

6Что осталось неясным

Какая страница «не найдено» нужна по старому адресу /contacts/new?

Вы выбрали «Страница не найдена». Без лишнего кода по этому адресу откроется страница «Контакт не найден»: «Возможно, ссылка неверная или контакт удалили» и кнопка «К списку контактов». По смыслу то же, но текст про контакт. Если нужна именно общая «Страница не найдена» — это небольшая доработка, скажите.

Остальные решения по умолчанию собраны в разделе 5 — если какое-то не подходит, план можно поправить до реализации.
