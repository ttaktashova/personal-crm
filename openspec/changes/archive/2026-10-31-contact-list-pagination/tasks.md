# Tasks

Автотестов в проекте нет, а тестовый раннер — новая библиотека (обсуждать с владельцем). Поэтому проверки ниже такие:

- `pnpm typecheck`, `pnpm lint`, `pnpm build`;
- SQL-запросы к локальной базе;
- разовые проверки через `pnpm tsx -e "…"`. Для модулей с `import "server-only"` — через `pnpm tsx --conditions=react-server` или SQL-запросом;
- ручные проверки в браузере на `pnpm dev`.

Перед кодом на Next.js — прочитать нужный гайд в `node_modules/next/dist/docs/` (правило `AGENTS.md`): `Link` и `scroll`, `useLinkStatus`, `useRouter` (`push` / `replace`), `cookies`, `searchParams` у страницы. Локальная база для проверок — 1000 контактов из `pnpm db:seed`: 20 страниц при 50 на странице, 40 при 25, 10 при 100. Временные базы для проверок создавать рядом с основной в локальном контейнере Postgres (`createdb` / `dropdb`), основную локальную базу не удалять.
